| File | Size | Alpha | Use |
|---|---:|---|---|
| `ui_bg_graphite_tile_512.png` | 512×512 | Opaque | Repeating graphite backdrop |

These are decorative surfaces. They carry no labels or gameplay states. The
texture is intentionally subdued in the center. The tiled sources use
periodic noise. Source: `../scripts/build_backgrounds.py`.
